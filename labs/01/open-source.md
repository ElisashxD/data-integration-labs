4. People. How many contributors does it have? Who decides what gets merged?  
   Pandas is an open-source project, so anyone can potentially contribute to it. There are pandas contribution guidlines. Information about how to contribute are given there.  After one has written their code in their feature branch and pushed the commits on the origin repository, a pull request is necessary to make the changes available to everyone.  If everything is deemed as fine by the repository maintainers the changes get merged into the project in the next release.   The final decision over pull requests are made by the Core Team.

5. Money. Who pays for the work: volunteers, companies, a foundation, donations? Look for a Sponsor button, a funding page or the project's website.  [The Website for Pandas](https://pandas.pydata.org/about/governance.html) states that its main financial source is the NumFOCUS Foundation. They may hold project trademarks, other intellectual property, helps manage project donations and is the parent legal entity for the project.  Decisons are made by the BDFL (Benevolent Dictator for Life). Currently this is Wes McKinney. This person decides who is part of the Core Team as well. Together these two entities determine who will collaborate on pandas. There is a possiblity for institutional funding as well.
