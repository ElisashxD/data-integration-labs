# Text 
  # heading 1
  ## heading 2
  ### heading 3
  #### heading 4
  ##### heading 5
  ###### heading 6
  There`s 6 headings! 

  Linebreaks are to be made by leaving one blank line.  
  Or you can use two spaces. 
  Using a backslash doesn´t work.

  *Italic*, **bold** and ***both*** use an increasing amount of asterics enclosing the word starting with one for italic, two for bold and three for both.  
  Strikethrough is achived by using two ~~tildes~~ enclosing the word.
  
`code` requires enclosing the text with single backticks. Alternatively you can use three of these enclosing a whole paragraph.

If you want these characters that help declare all the aforementioned text manipulations to show up without changing the text, you can put a backslash in front of the desired character. Like this: \*** 

# Lists
Making up a list can be done by using characters like -,* or +
- a
- b
* c
* d
+ e
+ f

If you need the list to be numbered, you start out just like you would any numbered list:
1. a
2. b
3. c
4. d
5. e
6. f

Instead of a dot behind the number, a \`)\` is fine as well

For specific lists like task lists you type a - first and follow it with brackets:
- [ ] a
- [ ] b
- [ ] c
- [ ] d
- [ ] e
- [ ] f

If the task is finished you can put an x in the brackets:
- [x] g
